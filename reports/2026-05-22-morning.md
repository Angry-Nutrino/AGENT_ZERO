### Q04 [CHAT] — Explain what asyncio.gather does in Python and why it matters for running tools in parallel. Answer from your training knowledge â€” no web search needed.

asyncio.gather takes multiple awaitables — coroutines, Tasks, Futures — and schedules them to run concurrently inside the same event loop. It returns a list of results in the order the coroutines were passed, preserving that sequence even if completion order differs.

In Agent Zero's architecture, this matters because DELIBERATE dispatches multiple tool calls simultaneously rather than sequentially. A single response might trigger five tool executions; gather runs them in parallel so total latency equals the slowest tool instead of the sum of all five.

### Q10 [CHAT] — What is the difference between a threading.Lock and an asyncio.Lock in Python? When would you use each one?

threading.Lock blocks an OS thread and is meant for code that actually runs on multiple OS threads—synchronous work, mixed sync/async code, or protecting shared state that background threads touch. asyncio.Lock suspends a coroutine cooperatively inside a single event loop and is meant for protecting async code that never leaves that loop.

Use threading.Lock when the protected section might block an OS thread or when the lock needs to be held across thread boundaries. Use asyncio.Lock when all access happens through awaitable coroutines in the same event loop and you want to avoid blocking the loop itself.

### Q16 [CHAT] — Explain what FAISS is and what it is used for in a vector search context. No web search â€” answer from training knowledge.

FAISS is Meta's open-source library for efficient similarity search and clustering of dense vectors. It handles the core problem of finding nearest neighbors in high-dimensional spaces where brute-force comparison becomes computationally prohibitive.

In vector search, FAISS builds specialized index structures on your embeddings—IVF for inverted file partitioning, PQ for product quantization compression, HNSW for hierarchical navigable small world graphs. These structures trade varying degrees of accuracy for speed, letting you query millions or billions of vectors in milliseconds rather than seconds.

The library also provides distance computation primitives (L2, inner product, cosine) and GPU acceleration paths. In your system, it powers the archive retrieval mechanism: MiniLM embeddings of document chunks are indexed, and a cosine similarity threshold of 0.35 determines whether relevant context gets injected before the Interpreter runs.
